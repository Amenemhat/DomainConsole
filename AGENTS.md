# DomainConsole: правила интерфейса

Все однотипные элементы используют общие ресурсы и шаблоны. Изменяя один стиль, проверяйте все аналогичные элементы в командах, WSUS, истории, настройках и диалогах.

- Панели действий открыты, значок в фиксированной левой колонке, подпись полужирная и выровнена слева. Основной запуск доступен без прокрутки. Режим показывает только свои действия.
- Общая компактная шапка остаётся на месте; каждый режим получает всю рабочую область под ней. Переключение режима не меняет выполнение задания.
- Раскрываемые блоки журналов имеют общий заголовок и рамку; разделители — короткую ручку с достаточной областью захвата.
- Палитра хранится в Theme.cs. Светлая тема соответствует согласованному макету: синий #0176E5, прогресс #01B254, фон дерева #E2EEF7, рабочий фон #F7FBFE, поверхность #F2F8FD. Предупреждающий текст оранжевый, значки внимания жёлтые. Цвета не меняются произвольно при отдельных исправлениях.
- Отключение учётной записи AD, доступность WinRM и результат WSUS различаются по смыслу и форме значка. Нет ответа не доказывает выключение компьютера; новая загрузка Windows не доказывает отсутствие флагов перезагрузки.
- В выводе сначала результат проверки/операции и следующее действие, затем подробности; служебные времена и ID внизу. Видимые даты без смещения часового пояса; время пользователя без секунд.
- Проверять реальную отрисовку Windows во всех режимах, трёх темах и широком/узком окне; генерация макета не является проверкой реализации. Сохранять выделение, прокрутку, редактор и копирование.
- Чтение/запись истории и тяжёлая обработка не должны блокировать UI. Кэши ограничены; проверять отклик на 400+ компьютерах и большой истории.
