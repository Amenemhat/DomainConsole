DomainConsole 0.41 · Windows x64

Опрос: один SYSTEM-сборщик Snapshot41 на клиенте, лимит 40 секунд, без параллельных экземпляров. После неизвестного исхода автоматические повторные запуски блокируются. Есть общая пауза новых подключений текущей консоли.
Диагностика и восстановление → Опрос и остатки Probe…: предварительный список, удаление только подтверждённых завершённых старых Probe и явное возобновление опроса клиента. Maintenance, рабочие задания и неизвестные процессы не удаляются.
Главная плашка и список компьютеров используют общую оценку готовности. Отдельной отрицательной карточки перезагрузки нет. Адреса в подписях только IPv4; подключение по IPv6 сохранено.
Обновление: закройте ВСЕ старые экземпляры консоли, замените приложение вместе с Agent, сохраните Data. Обновите все управляющие консоли. Уже переданные задания продолжают работу.
