# Карта переноса действий

| Прежняя кнопка/пункт | Сценарий/обработчик | Новое место |
|---|---|---|
| Проверить клиент | WsusDiagnostics_Click | Диагностика → Клиент WSUS |
| Помощник: диагностика Windows Update | UpdateWizardScript | Диагностика → Windows Update · очереди |
| Память и подкачка | MemoryDiagnostics_Click | Диагностика → Память и подкачка |
| Загрузка и установка | WaitingDiagnostics_Click | Диагностика → Загрузка и установка |
| Доставка отчёта (также помощник) | DeliveryDiagnostics_Click | Диагностика → Доставка отчёта |
| Восстановление отчётности | RecoverReport_Click | Восстановление → Отчётность |
| Defender (также помощник) | Defender_Click | Восстановление → Defender; внутри сохранены проверки и варианты восстановления |
| Перезапуск служб (также помощник) | RestartServices_Click | Восстановление → Перезапуск служб |
| Зависшие службы | ForceServices_Click | Восстановление → Зависшие службы |
| Очистка кэша (также помощник) | CacheCleanup_Click | Восстановление → Очистка кэша; все варианты и старые кэши сохранены |

Основные обновления, отчёт WSUS, внимание и остановка остаются на основной панели. Старый общий помощник заменён общим окном; уникальный UpdateWizardScript сохранён отдельным действием.
