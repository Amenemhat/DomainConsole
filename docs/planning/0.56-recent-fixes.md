- #154: серверный обзор виден весь цикл; обработанные записи, отсутствующие клиенты, ошибки, время завершения, последний полный обзор и расписание доступны из подробностей. Подсказки соответствуют серверному чтению.
- #155: лимит обычных последних клиентов; отдельные подтверждённые активные операции и явно помеченные закрепления; удаление из списка без удаления истории/AD и остановки задания.

Код новых удалённых операций, установки агентов и таймеров в эту порцию не добавляется. #157 (полный цикл идентичности группы N клиентов) — следующая порция до старого аудита. #123 и остальные непроверенные задачи остаются открытыми.
