# 0.55.1 — исправления после наблюдений владельца

## Изменения

- Прямой вызов WUA из сеанса WinRM для `fresh58` заменён на отдельную локальную задачу SYSTEM `DomainConsoleCSharp-ManualReboot59`. Она только читает состояние; не зависит от допуска фонового сборщика, не перезапускает службы и не устанавливает обновления.
- Одна фиксированная задача, блокировка между консолями, проверка её назначения/пользователя/лимита, IgnoreNew, предел выполнения 40 секунд и ожидания ответа 45 секунд. Повтор после завершения создаёт свежий результат; при занятой или чужой задаче возвращается явное сообщение. Нет постоянной блокирующей метки после сбоя.
- Старое отрицательное чтение WSUS больше не представляется текущим отсутствием клиента при ошибке чтения или восстановлении снимка.
- При устаревшем состоянии задания главная плашка различает чтение результата и ожидание следующего опроса. Индикатор показывает именно активное чтение, а не недоказанный прогресс установки. Неизвестный результат выполнения остаётся неизвестным.
- По выбору владельца предупреждения используют #FF8800, без затемнения; цвет настоящих ошибок не меняется.
- Диагностика неполной проверки показывает время последней попытки и сохранённое подтверждённое состояние перезагрузки, если оно есть. Сообщение классифицируется как предупреждение.
