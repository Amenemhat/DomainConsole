## Решение о выпуске

**Публикация не выполнена; функциональные Issues по этому прогону не закрывались.** Реестр содержит 105 задач, но построчная повторная приёмка всех их действующих условий не завершена. Этот документ не является `0.47.json` и не предназначен для прохождения acceptance_gate.py.

Блокирующие пробелы: реальное аварийное прерывание на изолированной Windows VM; сброс кэша с зависшей остановкой/восстановлением служб и исчерпанием бюджета; полный сетевой сценарий A/B/C с автоматическим продолжением (управляемая задержка UI уже проверена); завершение сверки реестра. Для установления причины клиентского 0xFFFF0000 нужен исходный stderr/журнал конкретного сброса, а не один итоговый код.

Полная приёмка требует доступного изолированного Windows-стенда с управляемой перезагрузкой/выключением. Производственные компьютеры для разрушительных проверок не использовались. Нельзя заменить эти пробелы формальным passed или массовым закрытием задач.


## Дополнительный прогон 28 октября: восстановление после остановки агента

Windows run [40707216675](https://github.com/Amenemhat/DomainConsole/actions/runs/40707216675), commit `714b4a98af954533b6d23654953a642eeec151e5`, завершился успешно. Последующая правка оформления окна остановки имеет отдельный run и не покрывается этим идентификатором.

- `Agent/InterruptionSmoke47.cs` запускает отдельный настоящий процесс агента и резко завершает его на четырёх контрольных стадиях: поиск, скачивание, установка, перед записью окончательного результата. WUA заменён стендовыми действиями: настоящие обновления и системные службы не изменяются. Для проверки двухминутного защитного интервала сначала проверяется отказ, затем старится только сохранённое поле Updated; системные часы/boot не подменяются.
- Живой исполнитель и занятый установщик не допускают освобождения. После подтверждённого исчезновения исполнителя старая запись сохраняется в резервной копии, исход помечается неизвестным/прерванным. Повторное согласование идемпотентно; слепой автоматический повтор установки запрещён.
- `Recovery47Checks.cs` проверяет полный путь консоли: Reconcile → ReconcilePlan → AdvanceMaintenance. Отказ release оставляет старую привязку; занятый WUA после release не создаёт новую работу; свежие факты допускают ровно один UpdateScan. Повторный тик не создаёт дубликат и не меняет выбранный клиент/режим.
- Исправлено согласование прерывания без новой загрузки Windows: старый Running не должен преждевременно закрывать план до подтверждённого освобождения.
- Пакет сборщика имеет ревизию47; проверены запрет отката более нового пакета и запрет замены при активной работе. LocalSmoke проверяет восстановление после уже завершившегося с ошибкой чтения, удаление/явное включение, один общий Task для повторного клика и свежий полный снимок. Reset не выдаёт Disabled за успех.
- `MaintenanceRegistration47.Script` обновляет остановленный подтверждённый исполнитель очистки по версии нового exe, вместо прежнего порога0.38. Проверены 11 сценариев, включая Running/Queued, более новую версию, неверный путь/аргументы/principal/hash и занятый файловый gate. Службы в этих проверках не останавливаются. Реальная локальная передача SYSTEM также прошла.

Это согласованная пользователем замена недоступного эксперимента с питанием на резкое завершение процесса. Она проверяет потерю исполнителя и восстановление протокола, но не сохранность файловой системы при отключении питания и не поведение настоящего CBS во время выключения.

## Что не закрыто этим прогоном

- #44 переоткрыта: общий hard timeout PowerShell при очистке кэша может обойти finally; 10 проверок обычных отказов не доказывают восстановление в этом случае. #120 остаётся открытой.
- #6: полноценная диагностика коллизий и перерегистрация SusClientId не реализованы; чтение идентификатора не равно всей функции.
- Полная поусловная приёмка105задач не завершена. Добавлен индекс всех задач/исходных блоков и связанных файлов, но он намеренно не является отчётом `0.47.json` и не разрешает закрытие Issues. Исторические заявления «выпущено» не скопированы в passed.
- Полная матрица реального домена, двух GUI-консолей, всех локалей Windows и системного DPI не выполнена. Уже имеющиеся подстановки/снимки отмечаются именно как такие проверки.

Новых закрытий функциональных задач и стабильной публикации по этому дополнению нет. Наличие этих пробелов не требует дополнительного разрешения владельца на обычную доработку; недостающие проверки нельзя заменить заявлением об успехе.
