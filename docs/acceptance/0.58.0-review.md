Последний доступный архив — [0.58.0 RC 2](https://github.com/Amenemhat/DomainConsole/releases/tag/v0.58.0-rc.2). Коммит `f76a7eb2a5c7917bfab59c84a56d46ce8f4a48b2`, [полный Windows CI успешен](https://github.com/Amenemhat/DomainConsole/actions/runs/45176668640), SHA‑256 ZIP `9d2bd10b3c8b6359c519b799fb1484ff5f29981567be98203304e84c32bef045`.
