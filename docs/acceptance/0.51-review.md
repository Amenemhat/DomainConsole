# 0.51: методы приёмки

Рабочая карта 114 условий. Окончательный commit, run, пакет и результат записываются после полного прогона; наличие сценария не означает passed.

Проверки выполняются в изолированном Windows runner. Реальные: SYSTEM-команды, WinRM, задачи, файлы, буфер обмена и ввод мышью/клавиатурой. Управляемые: время, удалённые факты boot/WUA/WSUS и сетевые ошибки. Резкое завершение собственного агента проверяет восстановление исполнителя, но не заменяет физическое отключение питания ОС. WPF viewport 1184×752/986.7×626.7 с растеризацией 120/144 DPI (125/150%) и растеризация значков 96/120/144/192 DPI не являются испытанием смены DPI физического монитора.

Поздние решения владельца: серый offline; шестерёнка только настройки; сборщик в шапке; зелёная успешная установка; сохранённый контроль перезагрузки и один поиск; события только переходов фаз; ограниченное ожидание без снятия защиты установки. Они заменяют противоречащие ранние варианты, остальные условия сохраняются.
