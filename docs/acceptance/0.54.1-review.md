# Проверка восстановления статусов 0.54.1

## Причина исправления

Результат обновлений перекрывался доступностью в двух местах: `AssessClientCore41` заменял законченную оценку на Unknown при потере связи, а `ComputerRow` дополнительно менял любой значок/цвет на Unknown/серый. Отдельный тест Status50Checks закреплял именно это старое поведение; теперь он различает завершённый результат и неподтверждённую текущую работу.

`PreserveReady43` отклонял сохранённый успех при любом ограничении чтения флагов. Ограничение чтения не является новым отрицательным фактом. Теперь проверяются фактические противоречия: подтверждённая работа установщика после проверки, новое задание, изменившаяся идентичность/загрузка, положительные флаги, ошибки/требуемые обновления/расхождение. Формат ready-proofs43.json не менялся.

## Регрессии

- SavedStatus55Checks десериализует ReadyProof43, совместимый с 0.53, и рассчитывает оценку при отсутствии live-отчёта. Проверяет сохранение прежней даты и успешного результата при Unknown/SavedConnected/Unreachable/Access.
- Проверяет независимые значки Success/Error/Reboot/Needed, ручное отключение, неудачный опрос флагов, приоритет нового reboot, ошибки/расхождения/текущей операции, новой загрузки и другой идентичности.
- Без сохранённого proof успех не возникает; очередь заданий до/после не меняется. Метод восстановления синхронный и не обращается к клиенту.
- Status50Checks сохраняет запрет анимации неподтверждённой работы без связи. Release28Checks сравнивает оценку до и после потери связи вместо требования превратить её в Unknown.
- Остальная обязательная Windows-матрица повторяется на точном выпускаемом коммите.

## Границы

Используются изолированные тестовые данные формата 0.53, а не реальная Data владельца. Проверка JSON — проверка совместимости сохранённого доказательства, не утверждение о наличии такого доказательства для каждого компьютера владельца. История не переписывается ради зелёного значка. Установленные обновления и системные службы не затрагиваются восстановлением статусов. Уже разрешённые планы обслуживания не отменяются.

Реальные обновления Windows в WUA-тестах заменены изолированными объектами; часть сервисных тестов использует doubles. Эти ограничения унаследованы от 0.54 и не выдаются за испытание производственной сети.
