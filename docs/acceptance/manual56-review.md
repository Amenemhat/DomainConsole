# Ручное управление — текущая проверка 0.54.3

Область: #145 и #146. Новая архитектура наблюдения штатного оркестратора не внедряется. #144 (сравнение разновременных результатов клиента и WSUS) остаётся отдельной открытой задачей.

Позднее согласование владельца: обычные ручные команды, их остановка и получение результата не зависят от переключателя фонового опроса и плана WSUS. Это заменяет старый запрет всех чтений при Master OFF **только для явно запрошенного ручного действия и сопровождения его задания**. Фоновые обзоры/сборщики и автоматическое продолжение при OFF по-прежнему не стартуют.

Реализация:
- PollingControl43.Manual56 отделяет отмену ручного запроса от поколения фонового опроса.
- TransportBudget41 использует отдельные ограниченные каналы для ручной передачи, результата и управления. Ручная блокировка ожидается до 30 секунд; отказ до передачи не становится неизвестным исходом установки. Обычный фон сохраняет запрет дубликатов.
- Manual56 сохраняется с заданием. Его результаты читаются при OFF, включая повторный запуск консоли. Отдельные очереди чтения исключают ожидание за фоновым запросом.
- Обычные CMD/PowerShell в разделе команд не захватывают запись WSUS и не ждут её исполнителя. Собственный ID задания и mutex предотвращают повторное выполнение одного задания. Встроенные операции установки по-прежнему координируются; ограничения Windows не выдаются за успешное выполнение.
- GuardJobControl56 позволяет остановить собственную обычную команду независимо от владельца плана WSUS. Идентичность исполнителя при принудительной остановке проверяется существующим механизмом.
- OrphanReservations56 и control56.ps1 снимают только ID без job.json/status.json/submitted.flag, без задачи/исполнителя и после защитного интервала. Ошибка чтения не означает отсутствие. Сохраняются резервная копия, остальные JobIds, владелец и план. Существующее задание не объявляется завершённым из-за возраста.
- Фиксированные кнопки связи (140 DIP) и опроса (68 DIP); длинный статус/индикатор во второй строке. Popup остаётся доступным без ошибки сборщика; доступна адресная диагностика/остановка/восстановление/переподключение.
- Последний отказ допуска выводится отдельно с временем, без подмены состояния текущей установки.

Проверки не считаются завершёнными до успешного точного Windows run и просмотра артефактов. Первый run 41721477636 скомпилировал обе программы, но обнаружил 4-пиксельное наложение текста связи; ширина скорректирована. Новая проверка содержит:
- независимость ручной передачи и отмены от занятого фонового/ручного канала;
- получение результата при OFF и отсутствие утечки ручного контекста в фон;
- реальный дочерний CMD-исполнитель при занятом WSUS mutex, без изменения владельца;
- сохранение живых/неизвестных/недавно зарезервированных заданий, снятие только отсутствующего;
- изолированный PowerShell 5.1 сценарий с backup, идемпотентностью, сохранением задач и процессов;
- отрисовку окна управления в трёх темах и прежнюю полную матрицу экранов.

Ограничения: поведение на производственных клиентах не проверялось. Ручное управление не гарантирует успешную установку при отказе самой Windows, недоступности клиента или отсутствии прав. Принудительное завершение конкретного исполнителя не выдаёт незавершённую установку за успех. Issues не закрываются автоматически.
