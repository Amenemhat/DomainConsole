# DomainConsole 0.31

- #37–#39: ожидаемый разрыв VPN не отменяет задание; сохранённая связь не становится неизвестной; завершённое наблюдение исчезает из текущей строки. Глобальный переключатель включает установку после успешного поиска и продолжение после разрешённой перезагрузки. Выключение запрещает будущие шаги, сохраняя начатую операцию.
- #40–#42: встроенный справочник 4302 HRESULT, 146 подробных русских карточек; одна основная причина вместо повторов. Неизвестный код обозначается явно, поиск по коду — из контекстного меню раздела.
- #43: сгруппированный отчёт WSUS, счётчик эффективного одобрения конкретного клиента; неизвестная применимость отдельно. Полная статистика свёрнута.
- #44: полный сброс через изоляцию каталога; первичная ошибка и стадия сохраняются. Отдельное удаление остатков ограничено по времени; повторный сброс не плодит каталоги.
- #45: сведения клиента, связь/аптайм/обновления, текущая операция и три последних события. История хранится локально по клиенту, фильтр и копирование. По умолчанию 30 дней, настраивается.

## Проверка

Windows CI собирает net462-агент и WPF net10 и выполняет проверки WinRM/SYSTEM, очередей, отмены, прогресса, истории, нового продолжения поиска в установку, справочника и синтетические проверки эффективных одобрений и изоляции кэша. Установка на реальных доменных клиентах тестовыми проверками не выполняется.

## Обновление

Сохранить Data. Автообслуживание WSUS включено по умолчанию, переключатель в шапке. Перезагрузка без отдельного разрешения не выполняется. Старый изолированный кэш может оставаться до успешной фоновой очистки; это отражается в журнале очистки. Старые пользовательские PowerShell-сценарии не переписываются. Исторические исходные тексты сохраняются.
