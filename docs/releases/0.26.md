# DomainConsole 0.26

## Исправления

- Вывод CMD/PowerShell передаётся как отдельные файлы, без потери раздела после CLIXML и без зависимости от текстовых разделителей (#7). Старые результаты можно перечитать с клиента.
- Ошибка 0x80070020 больше не приписывается status.json без фактического пути. Добавлено объяснение 0x80242014: завершение обновления ожидает перезагрузки (#8, #10).
- Последний неудачный поиск клиента с WSUS отделён от ошибок установки; подписи объясняют, что чтение статусов не запускает поиск (#9).
- Результат текущего задания расположен перед историей. Подробный отчёт получает события WSUS выбранного клиента и обновлений, сохраняет коды, время, неизвестные описания и отдельно сопоставляет клиентскую историю по ID/ревизии. Событие 167 не выдаётся за HRESULT. Код и объяснение дублируются в серверном отчёте; успешная история не окрашивается как ошибка (#10).
- В окне перезапуска служб добавлена галочка «Выбрать все службы» с частичным состоянием (#11).
- Стрелки дерева выровнены; нажатие на стрелку не переключает фокус к ранее выбранному компьютеру и сохраняет прокрутку (#12).

## Обновление

Закройте приложение, распакуйте новый ZIP в папку программы с заменой файлов. Сохраните свою папку Data. Установленный .NET для консоли не требуется; удалённый агент обновится при передаче нового задания. Уже запущенное задание само не заменяется.

## Проверка и ограничения

Windows-сборка, автоматические проверки вывода, WPF-навигации, выбора служб, источников кодов и серверных событий выполняются для точного коммита релиза. Реальный домен и WSUS пользователя из среды сборки недоступны; окончательное сопоставление событий проверяется в домене.

Подробные события запрашиваются только при чтении отчёта с ошибками, не для каждого компьютера фонового обзора. Окно событий — 14 дней, не более 300 записей; клиентская история — последние 500 записей. Недоступность источника или неизвестное описание явно отмечаются; автоматический сброс по одному Failed не выполняется. Возможность диагностики/ремонта клонов SusClientId остаётся отдельным открытым Issue #6.
