# DomainConsole 0.54.1

Исправление сохранённых статусов после перезапуска и обновления программы. Новая архитектура не входит в выпуск.

## Что изменено

- Недоступность клиента и отказ WinRM больше не заменяют сохранённый результат обновлений вопросительным знаком и серым цветом. Доступность показана отдельным значком.
- Сохранённое доказательство успешной полной проверки формата 0.53 читается без нового клиентского поиска. В плашке указаны исторический характер результата и дата.
- Ручное отключение и неудачное чтение флагов не стирают прежний успех. Неизвестный исход ещё выполняющегося задания остаётся неизвестным.
- Новый подтверждённый reboot, новая ошибка, расхождение источников, новая операция или смена идентичности не маскируются старым успехом. Отсутствующие доказательства не превращаются в успех.

## Обновление

Закройте консоль и сохраните резервную копию Data. Замените программу и каталог Agent, сохранив выбранную Data. Если используете резервную Data от 0.53, учитывайте: в ней нет истории операций, произошедших после создания этой копии. Не запускайте повторную установку только из-за отсутствия такой записи.

Для восстановления значков не нужно нажимать «Проверить обновления»: сохранённые доказательства читаются при запуске. Команда поиска обновлений остаётся отдельной операцией с автоустановкой. Уже существующие планы обслуживания этим исправлением не отменяются.

## Проверка и ограничения

Проверяются JSON формата ReadyProof43 из 0.53 без live-отчёта, отсутствие связи, отказ доступа, ручное отключение, неудачное чтение флагов, новые подтверждения и отсутствие выдуманного успеха. Восстановление не создаёт клиентских заданий. Полный [Windows run 41650830550](https://github.com/Amenemhat/DomainConsole/actions/runs/41650830550) успешен; коммит `e9b0d380c7f72e2ba75a27a4478c03ffbe520391`. Скачанный архив проверен: SHA-256 `b3cdd7a4174e6fd81fdb35985cbfd9048ea741239f17e15803354cb5c53f8ae0`, CRC исправен, обе программы 0.54.1.0, Data отсутствует. [Доказательства и границы](../acceptance/0.54.1-review.md).

Реальная Data владельца не предоставлялась. Исправлены обнаруженные причины перекрытия результата; отсутствие или несовпадение сохранённых доказательств требует отдельной диагностики, а не массовой повторной установки. Issue #142 остаётся открытым для проверки владельцем.
