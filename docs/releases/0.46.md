# 0.46

Подготовка выпуска: результаты проверки сборки будут добавлены перед публикацией.

- Восстановление записи прерванного до новой загрузки задания при проверке допуска. Сохраняется резервная копия; результат неизвестен, автоматический повтор установки запрещён. Работающий исполнитель, занятый WUA и незавершённое восстановление препятствуют освобождению.
- Сохранённое отсутствие флагов перезагрузки не окрашивается как предупреждение только из-за давности.
- Критерии без рамок, действия истории в заголовке, значки копирования, уведомление без сдвига разметки.
- Действие рекомендации и раскрываемые подробности опроса расположены в области результата; дубль «Главное» скрыт в подробностях операции.
- При потере свежего состояния активного задания отображается ограничение наблюдения; удалённое задание автоматически не перезапускается.
- События разных заданий больше не сворачиваются вместе. Значки поиска, загрузки и установки различаются.
- Исправлено преждевременное сообщение об успешном сбросе кэша. Добавлена диагностическая карточка WOF 0x80071160.

Ограничения: автоматическое восстановление в этой версии ограничено подтверждённой новой загрузкой; остановка задачи в пределах одной загрузки, произвольные команды с неизвестным исходом и незавершённое восстановление требуют отдельной диагностики. Возобновление установки с сохранённого процента не поддерживается: требуется свежая проверка результата Windows. Причина 0xFFFF0000 при сбросе кэша ещё не установлена.

Обновление: распаковать в отдельную папку, перенести Data при закрытой консоли; не запускать старую и новую консоли одновременно во время обновления.
