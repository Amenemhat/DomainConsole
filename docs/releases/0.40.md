# DomainConsole 0.40

Исправления по результатам проверки 0.39: #103–#108.

- Главная плашка и раздел «Главное» различают результат команды, сохранённые ошибки WSUS и неподтверждённое получение нового отчёта. Текущий процесс остаётся виден, предупреждения отчётности идут рядом. Время чтения серверных данных не обновляет дату отчёта клиента.
- Оранжевая карточка перезагрузки: число уникальных источников, короткие имена ключей, время проверки. Устаревшие данные и неполная проверка обозначаются явно. Кнопка «Проверить сейчас» на устаревшей карточке и в диалоге перезагрузки; причины и время также в подсказке кнопки. Проверка только читает состояние.
- «После перезагрузки: ожидание готовности» больше не отображается как ожидание самой перезагрузки. Событие новой загрузки использует новый снимок, а не предыдущий.
- Уведомления размещаются внутри информационной шапки и не перекрывают действия. Пустые ячейки шапки скрываются вместе с разделителем. Ручка вертикального разделителя дерева ориентирована вертикально.
- Пустые разделы диагностики, содержащие лишь имя файла, и точные дубликаты не выводятся. Ошибки получения диагностики и содержательные результаты сохраняются; исходные файлы не изменяются.
- Ошибки связи в истории показываются заголовком «Ошибка WinRM/аутентификации», без повторения полного текста. Полная причина остаётся в техническом журнале событий. Группировка по исходной причине, Ctrl/Shift и копирование сохранены.
- Нажатие имени копирует короткое имя без домена. IPv4/IPv6 не обрезаются. IP отображается меньшим шрифтом рядом с именем в шапке и последних компьютерах; подсказка указывает источник и время. Используется адрес существующей TCP-проверки; дополнительных DNS-запросов при отрисовке нет.

Проверка: Windows CI, сценарии расхождения результата команды и отчётности, старых/частичных/послезагрузочных флагов, копирования имён и адресов, сокращения ошибок и диагностических дублей; реальные снимки четырёх режимов в трёх темах и двух размерах окна. Сохраняется нагрузочный сценарий 450 компьютеров / 1000 заданий / 10000 событий.

Обновление: закрыть приложение, заменить весь пакет вместе с Agent, сохранить Data. Обновить все управляющие консоли. Выполняющиеся удалённые задания продолжают работу.
