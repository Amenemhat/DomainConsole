# DomainConsole 0.58.0

Windows x64. В этом выпуске ручные команды получают приоритет, ожидание отчёта WSUS имеет явный срок и отмену, а в карточке клиента отображаются источник и время доступных данных.

| Изменение | Как проверить | Ожидаемый результат |
|---|---|---|
| Приоритет ручных команд | Во время фонового опроса запустить ручную команду для этого ПК. | Ручная команда обрабатывается первой. Фоновая очередь других ПК продолжает работу. |
| Защита от повторной отправки | Повторно нажать ту же команду, пока передача не подтверждена. | Новое задание не создаётся. По исходному заданию можно проверить результат в истории. |
| Ожидание отчёта WSUS | Выполнить обслуживание с задержанной доставкой отчёта. | Ожидание можно остановить. После 10 минут появляется предупреждение, локальный результат установки сохраняется. |
| Просрочка отправки | Оставить подготовленное задание в очереди без передачи. | Через 5 минут появляется предупреждение о просрочке. Неизвестная доставка отображается отдельно. |
| Прогресс и сведения о клиенте | Проверить строки при ожидании, скачивании и завершении. Сравнить свежий и старый отчёты. | Анимация отражает стадию операции. Заголовок WSUS показывает дату отчёта клиента, время чтения отображается отдельно. Для недоступных сведений о сеансе указано состояние либо последнее известное имя. |

Распакуйте ZIP в отдельную папку и запустите `DomainConsole.exe`. При переносе действующей конфигурации закройте консоль и сохраните копию папки `Data`.
