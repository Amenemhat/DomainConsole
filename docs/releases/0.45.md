# DomainConsole 0.45

- В главной плашке три раскрываемых критерия: обновления, отчет WSUS, перезагрузка. Условия, источники и действия показаны рядом с результатом. Раскрытие читает только локальные данные. Ручное сворачивание сохраняется на время сеанса; одинаковый опрос не раскрывает группу заново.
- Неполная проверка и отсутствие аптайма не отменяют прежнее положительное требование перезагрузки. Время и источники сохраняются отдельно; доказанная новая загрузка требует повторной проверки, полная отрицательная проверка снимает требование.
- Подтвержденная перезагрузка имеет приоритет над ошибкой прежнего серверного отчета. Успешная установка и ожидание актуализации сервера показаны раздельно. Новый исполнитель сохраняет ID и ревизии успешно установленных обновлений; сопоставление не снимает независимые ошибки.
- Кнопка проверки перезагрузки находится у соответствующего критерия и не появляется посреди установки из-за одного возраста снимка. Кнопка связи проверяет WinRM и читает состояние, без скрытого сброса рабочего сборщика; восстановление остается явным служебным действием.
- Общий обзор отдельно считает пропущенные/отложенные и неполные/неудачные проверки. Для незавершенных целей предусмотрено до двух дополнительных адресных обходов с паузой не менее двух минут, через прежние ограниченные очереди и защитные паузы. Срок и список повторов сохраняются. Успешные клиенты не участвуют в этих повторах. Ручной обзор начинает новый явно запрошенный обход.
- Установка/поиск Windows, пользовательские команды, процессы служб и системные установщики автоматически не завершаются. Клиентские таймауты, единственный экземпляр сборщика и межконсольный допуск сохранены. Изменение статуса/раскрытие критерия не запускает удаленную операцию.
