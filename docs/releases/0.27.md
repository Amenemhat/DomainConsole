# DomainConsole 0.27

## Изменения

- Подтверждённое клиентом требование перезагрузки имеет приоритет основного значка, включая сохранённые ошибки WSUS. Сами ошибки и результаты не стираются (#14).
- После задания агент проверяет Windows Update API, RebootRequired, CBS RebootPending и PendingFileRenameOperations. Журнал содержит источник, время и ограничения проверки. Для выбранного клиента флаги перечитываются примерно раз в минуту; после перезагрузки статус согласуется заново.
- Убраны активные рекомендации очистки по прежней неудаче при более новой попытке, ожидающей перезагрузки. Подробности событий и истории находятся в журнале один раз; серверная сводка ссылается на этот раздел.
- Подключение существующего клиента по заданному IPv4/IPv6: «Подключение» → «Адрес подключения…» либо меню компьютера. Адрес можно изменить или вернуть подключение по имени (#15).
- Плюс рядом с поиском добавляет клиента по IP. Ручные записи сохраняются отдельной веткой под доменом. Если подтверждённое имя уже есть, программа предлагает использовать существующую запись.
- Подключение по IP использует отдельные учётные данные только на сеанс, HTTP с явно разрешённым конкретным адресом TrustedHosts либо настроенный HTTPS. Сертификаты не игнорируются. Пароль не сохраняется в Data/истории; между процессами передаётся защищённым DPAPI.
- Перед операцией по IP сверяются подтверждённые имя и MachineGuid. Задания сохраняют исходные параметры: смена адреса не перенаправляет старое задание автоматически.

## Использование IP

Введите IP и нажмите плюс или откройте параметры подключения существующего ПК. Введите учётные данные; при HTTP явно разрешите конкретный IP, если это требуется, либо используйте настроенный HTTPS. Проверьте соединение и сохраните. Для изменения TrustedHosts нужны права администратора на компьютере консоли; остальные записи сохраняются. Ограничения WinRM, NTLM и сети продолжают действовать. После перезапуска консоли учётные данные вводятся заново. При изменённой идентичности операция не выполняется.

## Обновление и проверка

Закройте консоль, замените файлы и каталог Agent, сохраните свою Data. Ранее переданные задания продолжают использовать прежний агент и адрес. В параметрах подключения можно явно обновить адрес существующих заданий с тем же подтверждённым идентификатором, без повторного запуска. Для старых заданий без сохранённой идентичности может потребоваться прежний адрес; автоматического переноса нет.

Windows CI проверяет сборку, удалённые задания, интерфейс, перезагрузку и изоляцию IP-сеанса/учётных данных. Реальный VPN, домен и WSUS пользователя недоступны из CI; их необходимо проверить в эксплуатации. MachineGuid вместе с именем служит защитой от случайной смены адресата, но не является криптографической идентичностью и может клонироваться вместе с образом. Диагностика клонов WSUS остаётся в Issue #6.
