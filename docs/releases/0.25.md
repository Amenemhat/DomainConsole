# DomainConsole 0.25

## Изменения

- Единые статусы WSUS в дереве и списке работы. Зелёная галочка — свежий успех; синяя — сохранённый/устаревший успешный снимок. Известные ошибки сохраняются с датой. Доступность WinRM, отказ в доступе, отсутствие записи WSUS и недостаток данных различаются. Время чтения сервера не подменяет время отчёта клиента. Issue #1.
- Фоновый обзор всех загруженных ПК: по 10 клиентов на запрос, пауза 2 секунды, один запрос одновременно. Вначале недавние; по умолчанию после открытия и раз в 24 часа. Интервал 1–168 часов, отключение автоматического чтения и остановка обзора. Только чтение сервера: поиск, установка и восстановление на клиентах не запускаются. Неудачное чтение сохраняет прежний снимок. Issue #2.
- Фильтр нескольких статусов со счётчиками и отдельными действиями «Отметить» / «Добавить в работу». Любые категории, предварительный список целей, без повторов и автоматического запуска заданий. Добавленные компьютеры сохраняются наверху рабочего списка. Счётчики учитывают текстовый поиск по всему загруженному списку; категории могут пересекаться. Issue #3.
- Значок необходимости перезагрузки и кнопка в шапке для текущего ПК. Задержка, сообщение, явное включение принудительного закрытия приложений. Отдельная отмена назначенного из шапки перезапуска; отсчёт использует собственный сигнал отмены, не зависит от принятия Ctrl+C и продолжает работать при закрытии консоли. Очередь управления независима от WSUS. Issue #4.
- Обычное имя открывает ПК, Ctrl по имени переключает галочку, Shift по галочке отмечает видимый диапазон. Дерево и список работы согласованы; свёрнутые и отфильтрованные строки не включаются в диапазон. Выбранный фильтр восстанавливается после закрытия. Issue #5.

## Проверка

Windows CI: сборка C# WPF и агента, интерфейс и история после перезапуска, локальное выполнение SYSTEM, чтение через WinRM, прогресс и отмена, параллельные очереди, ограниченные диагностические журналы. Для обзора WSUS проверены точное сопоставление имён, отсутствующие и неоднозначные клиенты и частичные ошибки. Отмена отсчёта проверяется на реальном агенте с подменённой командой shutdown: тест не перезагружает машину.

Проверки на тестовых данных не заменяют проверку в домене. Неудачное подключение WinRM не доказывает выключение компьютера. Полученный после задания отчёт WSUS не доказывает точную связь с конкретным запросом отправки.

## Обновление

Закройте консоль, распакуйте ZIP в новую папку и перенесите прежнюю папку `Data` рядом с `DomainConsole.exe`. Переносите весь пакет, включая `Agent`. Сохраните старую папку до проверки новой версии. Активные удалённые задания продолжаются на клиентах.

Готовый ZIP и `SHA256SUMS.txt` приложены к GitHub Release v0.25. Исходники для использования приложения компилировать не требуется.
