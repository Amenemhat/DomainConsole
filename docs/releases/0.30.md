# DomainConsole 0.30

## Изменения

- Актуальные признаки перезагрузки: новая загрузка обесценивает прежние требования; свежая полная проверка без флагов снимает старый статус. Неопределённый результат не подменяется положительным. Поддержаны сохранённые данные прежних версий.
- Опрос WUA/реестра/аптайма через ограниченный сбор под SYSTEM. Ошибки диагностики показываются в журнале один раз с раскрываемыми подробностями, а не в подсказке сети. Успешный следующий опрос снимает предупреждение.
- Отключённые учётные записи AD: серое имя, отдельный значок, фильтр с количеством и сохраняемый переключатель показа. Массовые операции их пропускают; ручное действие доступно.
- Очистка кэша и восстановление отчётности: остановка UsoSvc, wuauserv, BITS, cryptsvc, выбранная очистка, запуск всех существующих служб, затем поиск и запрос отчёта без установки. При ошибке следующий шаг не запускается.
- Режим «Полное обслуживание…»: поиск, загрузка и установка; после подтверждённой перезагрузки продолжение выбранного сценария. До трёх циклов и двух суток ожидания. Сам режим не разрешает перезагрузку, принудительную остановку или сброс кэша.
- Продолжения и ожидание отчёта сохраняются между открытиями программы; работа не зависит от выбранного клиента. Список «Требуют внимания» открывает ожидающие действия.
- Автоматическое восстановление отчётности после проверки/установки, если одновременно подтверждены старый отчёт WSUS и старая непустая очередь EventCache. Одна попытка для одной задержки, повторная диагностика перед запуском, исключение рекурсивных повторов. Текущая установка и активная загрузка не прерываются. После восстановления — поиск и запрос отчёта без установки.

## Автоматическое восстановление отчётности

По умолчанию включено в настройках отчётности; там же задаётся возраст отчёта (24 часа по умолчанию). Одна только неполная диагностика, недавний отчёт или пустая/новая очередь очистку не запускают. Проверяются источник WSUS, идентичность цели, доступность диагностики и готовность клиента. При ожидании перезагрузки восстановление откладывается.

Автоматически удаляются только EventCache/EventCache.v2 без резервной копии. Download, DataStore, политики и идентификатор WSUS не сбрасываются. Перед фактической очисткой очередь повторно проверяется на клиенте. Если безопасный запуск не удался за два часа либо восстановление завершилось ошибкой, требуется ручное решение. После одной попытки прежний отчёт повторную очистку не запускает; новый эпизод допускается только после более нового отчёта и суточного интервала.

Свежий отчёт подтверждается данными сервера; успешное завершение команд отправки само по себе не доказывает приём WSUS.

## Проверка

Windows-сборка WPF и net462-агента, локальный SYSTEM и реальный WinRM, интерфейс/история после повторного запуска, старые и новые reboot-снимки, продолжение обслуживания без дублей, выбор отключённых записей AD, политика автоматического восстановления, его состояние после перезапуска и ошибка без повторов. Очистка проверяется на временных каталогах и подставных службах: старая/новая очередь, занятый установщик, сохранность Download/DataStore и запуск всех служб.

Реальная установка обновлений и получение отчётов в домене проверяются администратором на клиентах.

Issues: #31, #32, #33, #35. Диагностика дубликатов SusClientId (#6) остаётся отдельной задачей.

## Обновление

Закройте консоль, распакуйте новый пакет с заменой файлов программы. Сохраните папку **Data**: в ней история, адреса клиентов, статусы и планы продолжения. Уже переданные клиентские задания продолжают работать. После открытия консоль восстанавливает наблюдение; новые продолжения запускаются при работающей консоли.
