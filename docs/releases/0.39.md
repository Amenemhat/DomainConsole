# DomainConsole 0.39

Исправления по результатам тестирования 0.38: #95–#101.

- Команды, история и настройки используют всю рабочую область под общей шапкой. Панели WSUS показываются только в режиме WSUS.
- Действия команд и истории открыты: единые кнопки, фиксированная колонка значков, полужирные подписи слева. Запуск команды закреплён над прокруткой; наборы шагов, импорт, экспорт и параметры сохранены.
- Цвета светлой темы взяты из согласованного макета. Оранжевые предупреждения, жёлтые значки внимания, цветные компьютеры и серверы. Отключение учётной записи AD и отсутствие ответа различаются по форме.
- Разделители двух строк шапки, полужирное имя пользователя и обычное время, компактное «Ответ: < 1 мин».
- Общие рамки и заголовки раскрываемых журналов; короткие ручки разделителей; более компактная история событий с Ctrl/Shift и копированием.
- Индекс заданий на один цикл обновления, кэш группировки истории, чтение и последовательная запись событий вне UI-потока, подавление уведомлений неизменившихся строк и пересечения циклов обновления. События немедленно видны в памяти; при закрытии ожидается запись, неудачные записи сохраняются для повтора.
- Подтверждение загрузки Windows выделено зелёным, непроверенные флаги — оранжевым; общий значок предупреждения. Новая полная проверка уточняет результат.

Проверка: сборка и тесты Windows, переключение четырёх режимов в трёх темах и двух размерах окна, сохранение истории после перезапуска, нагрузочный сценарий 400+ компьютеров / 1000 заданий / 10000 событий. Фактические результаты проверок фиксируются в выпуске после завершения CI.

Обновление: закрыть приложение, заменить весь пакет вместе с Agent, сохранить Data. Обновить все управляющие консоли. Выполняющиеся удалённые задания продолжают работу.
