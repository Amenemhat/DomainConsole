# 0.51 — рабочий журнал приёмки

Актуальные изменения: [0.51.md](0.51.md). Поусловная карта: [0.51-review.md](../acceptance/0.51-review.md).

После требования завершить выпуск добавлены реальные Ctrl/Shift/Ctrl+C/Ctrl+A в истории, WPF-масштабирование 125/150%, границы дат и часовых поясов, связанный сценарий перезагрузки/восстановления/единственного поиска, матрица 7 видов операций × 4 результата, выгрузка журналов с закреплённой целью и отказом скачивания, известный/неизвестный источник sharing violation, реальный reg.exe через агента.
