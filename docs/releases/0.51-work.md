# 0.51 — рабочий журнал приёмки

Актуальные изменения: [0.51.md](0.51.md). Поусловная карта: [0.51-review.md](../acceptance/0.51-review.md).

После требования завершить выпуск добавлены реальные Ctrl/Shift/Ctrl+C/Ctrl+A в истории, WPF-масштабирование 125/150%, границы дат и часовых поясов, связанный сценарий перезагрузки/восстановления/единственного поиска, матрица 7 видов операций × 4 результата, выгрузка журналов с закреплённой целью и отказом скачивания, известный/неизвестный источник sharing violation, реальный reg.exe через агента.

Проверки обнаружили и исправили: изменение дат внутри обычного вывода; сокращение повторяющихся строк в канале WSUS; потерю разделителя между форматированной служебной секцией и буквальным выводом. Для повреждённого удалённого JSON добавлена ограниченная локальная диагностическая запись.

Итоговый исходный commit: `34a873154b20d420a2084a9f7089845c9d8aaa00`. Windows run [40946218625](https://github.com/Amenemhat/DomainConsole/actions/runs/40946218625) завершён успешно, 57/57 этапов. Точный ZIP скачан, проверены SHA-256, CRC и версии EXE/агента 0.51.0.0. Осмотрены 48 снимков матрицы интерфейса и отдельный снимок успешной установки с предупреждением о перезагрузке. Все 114 условий и 11 регрессий приняты в `docs/acceptance/0.51.json`.

Дополнительно исправлено разделение зелёного заголовка успешной установки и предупреждения о перезагрузке; частичный успех не получает успешный заголовок. В масштабированных снимках ожидание применения темы включено до захвата кадра.

0.51 выпускается обычным релизом. Историческое расследование #120 и задачи последующих порций остаются открытыми; физическое отключение питания и смена DPI монитора не выдаются за выполненные испытания.
