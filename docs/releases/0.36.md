# DomainConsole 0.36

## Изменения

- #70: повторы всех типов событий с раскрытием появлений, явный выбор и копирование записи/выбранных/всех.
- #71: краткие местные даты без смещения в пользовательском выводе; исходные UTC-значения сохранены. Старые результаты форматируются при показе.
- #72: крупнее вкладки и симметричный векторный значок настроек.
- #73: главный результат и следующее действие вверху, технические сведения задания внизу. Прежнее обслуживание отделено от успешного ручного действия.
- #74: ненулевые ошибки/перезагрузка в сводке WSUS; ошибка в панели клиента ведёт к подробностям.
- #75: контрастные полужирные имена, отключённые в AD приглушены и отмечены перечёркнутым монитором; подробная подсказка.
- #76: единое окно диагностики/восстановления без дублирующего помощника, сохранены все сценарии; компактная основная панель без конфликтующих фиксированных ширин.
- #77: внимание — актуальное действие/причина, цвет и отдельное отображение автоматического ожидания; единый счётчик уникальных клиентов.
- #78: Ctrl/Shift выбор нескольких процессов зависших служб, единое подтверждение, последовательное выполнение и повторная проверка идентичности каждого PID.

## Проверки

Windows-сборка приложения и агента; UI после перезапуска, три палитры/компактное окно, история/группировка, даты, сводка, сценарии диагностики, SYSTEM/WinRM и защитные проверки принудительного перезапуска. Пакет, контрольная сумма и снимки проверяются до публикации. Реальное окружение AD/WSUS администратора не доступно в CI.

## Обновление

Закройте приложение, замените DomainConsole.exe и каталог Agent из ZIP. Сохраните Data. Уже переданные задания используют прежний исполнитель.
