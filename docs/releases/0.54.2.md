# DomainConsole 0.54.2

Исправлена причина сброса сохранённых успешных статусов при переходе с 0.53 на 0.54/0.54.1: изменённый ключ подключения больше не делает старые отчёты и подтверждения успеха невидимыми.

- Сохранённые ключи 0.53 читаются для неизменённого подключения. Отчёт WSUS, итоговый статус и адрес клиента восстанавливаются без повторного поиска обновлений.
- Даты проверок не заменяются временем запуска программы. Сохранённые наблюдения установщика также учитываются.
- Ключи текущих сетевых запросов остаются строгими: изменение поколения подключения, адреса или идентичности не позволяет принять старый ответ.
- Новые ошибки и требования перезагрузки сохраняют приоритет. Отсутствующие данные не превращаются в успех.

Закройте консоль, замените программу и Agent, сохранив текущую Data и резервную копию. Для восстановления статусов запускать проверку или установку на клиентах не требуется. Старая резервная копия не содержит операций, выполненных после её создания.

Воспроизведение до исправления: Windows run 41677038692. Проверка использует обезличенный пример буквального старого ключа, реальный запуск приложения и повторный запуск, без сети. Предыдущий тест 0.54.1 ошибочно создавал ключ через новую функцию и поэтому не обнаружил несовместимость. Новая архитектура не внедряется; #142 и #143 остаются открытыми для проверки владельцем.
