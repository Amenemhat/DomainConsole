# DomainConsole 0.59.0 RC 1

Предварительный выпуск для Windows x64 из коммита `1df2700a8ac451f5db08ede6223730552a1faab1`. Полный автоматический Windows-прогон этого пакета прошёл.

| Изменение | Как проверить | Ожидаемый результат |
|---|---|---|
| Остановка зависшего скачивания | Во время скачивания выбрать «Остановить скачивание сейчас». | Запрос отправляется сразу. При отсутствии завершения через 10 секунд консоль сверяет этап и принадлежность агента перед принудительной остановкой. Исход фоновых передач Windows проверяется отдельно. |
| Возврат после перезагрузки | Дождаться истечения срока, когда готовность после перезагрузки не подтверждается. | Консоль выполняет один контрольный поиск без установки. Повторный запуск консоли не дублирует поиск. |
| Наблюдение за Windows Update и WSUS | Обновить обзор WSUS и выбрать клиент со свежим нормальным отчётом. | Статус опирается на серверный отчёт. При обслуживании консоль учитывает штатную загрузку и установку Windows Update. |
| Выделение и статусы | Выделить диапазон строк клавишей Shift и проверить компьютер с требованием перезагрузки. | Выделяется диапазон. Перезагрузка отличается цветом от обычного предупреждения. |

Массовая перерегистрация WSUS остаётся на приёмке. На предыдущем стендовом пакете четыре клиента не дошли до смены идентификаторов из-за тайм-аутов или отказа доступа при проверке активности Windows Update. [Результаты стенда](https://github.com/Amenemhat/DomainConsole/actions/runs/45586107371/artifacts/15012653461)

Распакуйте ZIP в отдельную папку и запустите `DomainConsole.exe`. При переносе конфигурации закройте действующую консоль и сохраните копию папки `Data`.
