# DomainConsole 0.54

Кандидат: публикация выполняется после проверки точного Windows-артефакта. Новая архитектура наблюдения за штатным оркестратором (#137) в этот выпуск не входит.

## Изменения

- Поиск по политикам клиента, явный WSUS или Windows Update. Отсутствие UseWUServer=1 больше не запрещает обычный поиск; политики не меняются. Источник сохраняется при продолжении.
- После успешного поиска найденные применимые обновления устанавливаются автоматически. Это обозначено в подтверждении запуска и подсказке кнопки. Автоперезагрузка этим не разрешается.
- Различаются текущая операция, неизвестный исход старого задания, предыдущий отчёт WSUS и расхождение клиентского/серверного результата. Новое успешное чтение флагов не маскирует ошибку обновления.
- Опрос и его подробности рядом со связью. Доступны ручное отключение и проверяемое переподключение по IP; старые ответы не возвращают прежний адрес. Для переноса управляющих действий требуется совпадение идентичности компьютера.
- После штатного запроса остановки доступно отдельное завершение собственного агента с проверкой принадлежности процесса. Операция Windows Update при этом может продолжиться; перед повтором требуется сверка.
- История результатов отдельных обновлений сохраняется сразу. Повторное чтение неполных данных не стирает установленные пакеты. Восстановление из WUA привязано к точному пакету и инициатору задания.
- Ожидание отчёта составляет 10 минут от запроса. История содержит запрос, обнаружение нового отчёта и задержку; серверное время и время обнаружения различаются. При задержке проверяется очередь; неизвестный размер не показывается нулём.
- При расхождении доступны свойства точных обновлений WSUS: ревизии, одобрения, группы и замена. Диагностика не меняет одобрения.
- Сетевая диагностика различает успешный запуск команды и неуспешное TCP-подключение. Показываются маршрут, интерфейс и прокси.
- Убраны повторяющиеся разделы перезагрузки и общие отложенные файловые операции. В WSUS остаётся короткая строка флагов; коды шагов перенесены в сведения о задании.

## Границы

Текущий пакет исправляет работу консоли; он не устраняет автоматически пересечение VPN-подсетей, повреждение Defender или политики организации. Старые установки без однозначного идентификатора инициатора не приписываются консоли. Существование старой BITS-задачи или TiWorker само по себе не даёт права автоматически завершать установщик.

Отдельная функция диагностики дубликатов и перерегистрации SusClientId (#6) остаётся открытой в следующей порции. Это новая функция, а не скрыто объявленное исправление текущего пакета. #141 не закрывается до окончательной сверки всех наблюдений владельца.

## Обновление

Закройте старые экземпляры консоли. Сохраните папку Data и резервную копию текущей программы. Замените программу вместе с каталогом Agent. Переданные клиентам задания не запускайте повторно только из-за смены версии: сначала прочитайте их результат.

## Проверка

Идентификаторы точного исходного коммита, Windows run и SHA-256 будут добавлены после успешной проверки. Этот документ не является подтверждением опубликованного релиза.
