# DomainConsole 0.44

- Требование перезагрузки больше не исчезает через пять минут. Для старого положительного результата сохраняется предупреждение с временем проверки; новая загрузка Windows переводит его в ожидание повторной проверки флагов. Свежая полная отрицательная проверка снимает требование. Проверка доступна прямо под главным результатом.
- Успешный поиск внутри полного задания установки учитывается при оценке готовности, как и отдельный поиск. Неизвестные данные не превращаются в успешный результат.
- Сохраненная фаза плана больше не подменяет фактический результат клиента. Исходное время и срок плана сохраняются; повторное принятие того же задания не оживляет завершенный план. Лимит автоматического продолжения — двое суток. Это не таймаут установки Windows.
- В истории событий есть адресное действие «Завершить план…»: прекращает автоматическое продолжение и непереданные автоматические шаги, сохраняет выполняющиеся задания, затем перечитывает состояние при включенном опросе.
- Исправлено скрытое ограничение вывода последними 80 строками. Выбранный результат читается последовательно в пределах 1 МБ, файлы шагов располагаются по номеру. Большой результат получает явное сообщение об ограничении; полные файлы доступны через «Журналы».
- Рядом со служебным ограничением доступно «Завершить и повторить». Сначала подтверждается остановка принадлежащего сборщика; новая проверка допускается после двухминутной паузы. Если остановка не подтверждена, новый экземпляр не создается. Автономные пределы 45/50/60 секунд сохранены, повторные ошибки ограничены существующими паузами и блокировкой. Установка обновлений, пользовательские команды и службы Windows автоматически не завершаются.
- Переключатели «Опрос» и «Авто» одинакового вида расположены друг над другом; настройки отделены слева разделителем.
- Для преобразования WindowsUpdate ETL используются сделанные копии; исчезнувший при ротации файл не прерывает копирование остальных. Ограничение преобразования сохраняется отдельно.

Глубокая проверка хешей и распаковка CBS-манифестов в выпуск не включены по согласованному решению.
