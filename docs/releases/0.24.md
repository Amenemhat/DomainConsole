# DomainConsole 0.24

Проверенная сборка: [Windows Actions](https://github.com/Amenemhat/DomainConsole/actions/runs/38701030223), коммит `4e506bdc85583f902e14966301034530095b2278`.

## Изменения

- История по компьютерам: поиск, разделы Команды/WSUS, сортировка и плотные строки.
- Результат выбранного задания отделён от фоновой очереди BITS и её прогресса.
- После успешного завершения скрываются устаревшие рекомендации.
- Обработаны отсутствие status.json, согласование заданий после перезагрузки и отмена неработающих записей с сохранением частичных результатов.
- Исправлена передача UTF-8; проверка подключения вынесена в отдельное окно.
- Разные цвета CMD/PowerShell, сохранение последнего режима и выбор оболочки при распознанном несовпадении.
- Добавлены диагностика памяти и подкачки и рекомендации для соответствующих кодов ошибок.
- Простая управляющая команда перезагрузки не ждёт зависшую обычную очередь.
- Нижняя строка заменена временными уведомлениями; исправлено направление горизонтальной прокрутки истории.

## Проверка и обновление

Windows CI завершён успешно; целостность ZIP и SHA-256 сверены. Проверенный архив Actions: `502013ca2782c80fbc18526a9de6b91c9854a70ad589122e87078baa106c0ee9`.
