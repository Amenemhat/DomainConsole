# DomainConsole 0.57.0 — кандидат

## Проверки оператора

| Изменение | Как проверить | Ожидаемый результат |
|---|---|---|
| Идентификаторы WSUS (#157) | В контекстном меню дерева AD выбрать проверку идентификаторов. На изолированном стенде взять компьютеры из разных OU с одним SusClientId. | Окно показывает имена, проверенные ID, источник и охват. Повторный щелчок открывает тот же проход. Диагностика только читает данные. Проход по всему списку запускается отдельно. |
| Перерегистрация группы (#157) | На стенде подтвердить список участников, дождаться регистрации и свежих отчётов на тестовом WSUS. Один участник сначала недоступен или занят установщиком. | У каждого подтверждённого участника свой новый ID и серверный отчёт. Занятый остаётся в ожидании. Требуется отдельное подтверждение для дополнительных целей. |
| Последние компьютеры (#161–#163) | Задать лимит 5, взять A и B, задержать ответ A. Добавить через обзор проблемный недоступный ПК и ещё пять обычных. | B виден первым до ответа клиента. При ответе A порядок сохраняется. Готовые находятся под общей подписью. Массовое добавление подчиняется ротации. Для старого закрепления доступно «Открепить · вернуть в обычную очередь». |
| Отключённая учётная запись AD (#164) | Сравнить отключённый сервер, отключённую станцию и временно недоступный включённый ПК в дереве и в последних. | Для отключённой записи после галочки видны тип устройства, имя и один знак отключения, в одном приглушённом цвете. |
| Потеря связи (#165, #166) | На стенде разорвать WinRM во время установки на 24%. Отдельно оставить связь рабочей и тот же процент на час. | При подтверждённом обрыве последнее измерение сохраняется до 15 минут. Затем видны время связи и прежний этап. Доступный клиент остаётся доступным при неизменном проценте. |
| Перезагрузка (#167) | На тестовой цели с занятой очередью запросить перезагрузку, проверить квитанцию, отмену до отправки, потерю ответа и повторный клик из второй консоли. | Ручной запрос идёт по каналу управления. Отдельно видны назначение и новая загрузка. Очередь других ПК работает. |
| Срок жизни данных (#168) | При недоступном клиенте сравнить флаги возрастом 23:59 и 24:00, старый и свежий отчёты WSUS. | После суток текущие локальные флаги неизвестны, время и источники доступны в подробностях. Счётчик из устаревшего отчёта виден как исторический. |
| Ошибка отрисовки (#160) | Проверить сценарий повторного HRESULT 0x88980406 в Windows CI, затем запустить приложение с параметром `--software-rendering`. | Одно системное уведомление, последний диагностический файл в `Data/Diagnostics/last-render-failure.txt`, завершение процесса. Аппаратная причина исходного происшествия требует журнала конкретного ПК. |

Состояние проверки кандидата отслеживается в [PR #169](https://github.com/Amenemhat/DomainConsole/pull/169). Проверки группового исправления выполняются на изолированном WSUS. Текущая опубликованная версия указана в README.

При обновлении закройте консоль, сохраните копию папки Data и перенесите её в каталог новой версии. Перенос сохраняет историю, закрепления и параметры опроса.
