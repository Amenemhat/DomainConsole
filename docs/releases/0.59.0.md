# DomainConsole 0.59.0

| Что изменилось | Как проверить | Ожидаемый результат |
|---|---|---|
| Групповая перерегистрация WSUS | Откройте «Проверить идентичность» у клиента с общим SusClientId. Сверьте найденные устройства и подтвердите исправление на тестовой группе. | Консоль показывает ход по каждому ПК. Подтверждение появляется после создания нового ID и получения свежего отчёта WSUS для этого устройства. |
| Переход от скачивания к установке | Запустите обслуживание тестового ПК с готовым кэшем или со штатной загрузкой того же обновления. | После проверки применимости и готовности пакета установка продолжается по исходному запросу. Готовые данные используются повторно. |
| Продолжение скачивания BITS | В фоновой активности выберите приостановленное или подтверждённое застоявшееся задание Windows Update. | Сохраняются GUID и загруженные данные. Возобновление подтверждается ростом байтов. Автоматическая попытка требует настроенного разрешения и подтверждённого пакета WSUS. |
| Остановка зависшего скачивания | Во время скачивания выберите «Остановить скачивание сейчас». | Сначала отправляется запрос отмены. После ограниченного ожидания исполнитель может быть остановлен после проверки его принадлежности и стадии. Итог доступен в истории. |
| Ожидание после перезагрузки | На тестовом ПК дождитесь окончания срока проверки готовности после перезагрузки. | Запускается один контрольный поиск с запросом отчёта. Установка и перезагрузка для этого задания отключены. |
| Обзор WSUS | Обновите обзор для ПК со свежим нормальным отчётом и для ПК с проблемой. | Консоль показывает готовность по отчёту здорового ПК. Свежесть отчётности и ошибки отображаются отдельно. |
| Ручное восстановление сборщика | Запустите восстановление тестового сборщика при фоновом опросе и проверьте результат. | Ручная операция получает допуск первой. Консоль подтверждает работу сборщика по свежему снимку. |
| Выделение, пользователь и перезагрузка | Проверьте Shift в дереве AD и списке последних компьютеров, шапку клиента и требование перезагрузки. | Shift отмечает видимый диапазон, подпись «Пользователь» показывает сохранённые сведения с их временем, статус перезагрузки выделен цветом `#FC03FC`. |
| Действия фоновой загрузки | Разверните «Фоновую активность клиента» в небольшом окне со сведениями о длинных путях. | Кнопка скорости доступна над прокручиваемыми подробностями. |

Для обновления сохраните копию папки `Data`, закройте предыдущую версию и распакуйте ZIP в отдельную папку. Запустите `DomainConsole.exe`.
