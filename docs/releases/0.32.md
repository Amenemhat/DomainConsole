# DomainConsole 0.32

- #47: компактная шапка с цельной панелью связи и перезагрузкой; переключатель автообслуживания. Горизонтальные вкладки, настройки через шестерёнку. Три последних события и встроенная раскрываемая история рядом с активностью. Удалены лишние кнопки дерева, счётчик отмеченных снизу. Поля ввода и вывода получают больше места, отчёт WSUS обведён отдельной панелью. Палитры Серый, Графит, Лиловый; полная область нажатия у шевронов.
- #48: сериализуются данные событий без кистей WPF; текущие и сохранённые события объединяются, ошибки сохранения видны.
- #49: после скачивания журналов задания открывается папка; показаны ход и результат сохранения.
- #50: PendingFileRenameOperations сохраняется с парами путей как отдельная информация. Одни общие файловые операции не означают требование перезагрузки Windows Update и не останавливают обслуживание. WUA и CBS сохраняют приоритет. Записи реестра не очищаются.

## Проверка

Windows CI: сборка WPF и net462-агента, SYSTEM/WinRM, очереди и отмена, отчётность, реальное сохранение/чтение событий, обработка старого ожидания перезагрузки, три палитры при 1000×640 и 1366×768. Снимки интерфейса проверяются перед публикацией. На доменных клиентах установка тестами не запускается.

## Обновление

Закройте приложение, замените файлы пакета, сохраните Data. Выбор палитры в настройках. Автообслуживание остаётся включённым по умолчанию; перезагрузка — по отдельному разрешению. Старое ошибочное ожидание уточняется свежим опросом клиента. Историю событий, которую предыдущая версия не смогла записать на диск, восстановить нельзя.
