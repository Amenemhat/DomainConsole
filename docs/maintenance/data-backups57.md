# Архивы состояния консоли

В настройках доступны создание проверенного ZIP вручную и открытие папки Backups рядом с приложением. Архив содержит сохранённые JSON верхнего уровня Data (история, настройки, статусы, планы), журналы событий Data/Events/*.jsonl из подкаталогов клиентов, manifest с датой UTC и SHA-256 каждого файла. Это не архив программы, удалённых журналов или хранилища учётных данных Windows. Для переноса сохраняйте папки Data и Backups вместе.

При запуске до создания окна проверяется синтаксис JSON верхнего уровня. Журналы событий архивируются как исходные байты с контрольными суммами; их исторические строки не блокируют запуск. Из исправных данных создаётся автоматический ZIP при запуске и после сохранения данных при штатном закрытии. Хранятся последние 30 автоматических архивов; ручные не удаляются. Неуспешная проверка не заменяет прежний архив. Первая установка этой функции не создаёт копию задним числом: если данные уже повреждены и архива нет, потребуется ранее сохранённая рабочая Data.

Если обнаружено повреждение, выбирается последний полностью проверенный архив, содержащий все повреждённые файлы. Пользователь видит дату копии и подтверждает восстановление. Если такого архива нет, можно выбрать ZIP DomainConsole вручную. Восстанавливаются только повреждённые файлы. Их оригиналы и происхождение восстановления сохраняются в Backups/damaged-*. Прерывание восстановления не удаляет оригиналы; повторный запуск снова проверяет Data. Отмена закрывает приложение до создания рабочего окна, без подмены данных пустыми значениями.

После восстановления отправка сохранённой очереди, автоматические планы, продолжения после перезагрузки и восстановление отчётности приостановлены. Ручная отправка нового задания и чтение доступны. После сверки клиентов и отмены ненужной очереди оператор явно разрешает автоматику в настройках. Ограничение сохраняется между запусками.

Запись JSON использует уникальный временный файл, Flush(true) и замену назначения. Это уменьшает риск частичного файла, но не гарантирует сохранность при неисправном накопителе или контроллере. Архив на том же диске не защищает от потери диска; ручную копию можно перенести отдельно.

Ошибки конструктора и загрузки записываются полностью в Diagnostics/startup-*.txt. Синтаксически корректный JSON с несовместимой моделью не восстанавливается автоматически: такой сбой остаётся диагностируемой ошибкой запуска.

Проверки: BackupTests использует только синтетические файлы; проверяет нулевой хвост, контрольные суммы, сохранение оригиналов, неповреждённых соседей, повторное чтение, неполные архивы, временные записи и ограничение числа копий. Приёмка WPF и полного Windows workflow требуется отдельно перед выпуском.
